# Learn LLM from Scratch to Production

The Complete, No-Black-Box Path to Becoming an LLM Engineer

Everyone can call an API. Almost nobody can tell you what actually happens between your prompt and the model's response — or build any of it themselves.

This book closes that gap. It's a 25-chapter, hands-on curriculum that takes you from "I can write Python" to "I built a GPT from scratch, fine-tuned it, wired it into an agent, and shipped it to production" — with every single concept implemented in real, runnable code before it's ever used as a black box.

No import transformers on page 1. You build the transformer first.

## Who this is for

You're a developer (any language, any background) who wants to actually understand LLMs — not just prompt them. Maybe you've followed tutorials that call model.generate() and felt like something was missing. This book is the missing part.

No ML degree required. No hand-waving either.

## What makes this different

Nothing is a black box. Backpropagation, tokenization, attention, RoPE, LoRA, RAG — you implement each one by hand before you're shown the production-grade library version.

Every chapter ships a working project, not just a code snippet. You end each chapter having built something, not just read about it.

The code is verified. Every extractable code block in this book has been executed end-to-end — including the full training chain (autograd → MLP → GPT → nanoGPT) actually training, for real, on ordinary hardware. Bugs found in review were fixed, not swept under the rug.

A 168-day companion roadmap tells you exactly when to read which chapter if you want a structured, day-by-day path — or skip it and go at your own pace.

## What you'll actually build

### Part I 
Foundations. A hand-rolled autograd engine (micrograd), a bigram-to-MLP language model, and — by the end of Part I — your own GPT, built from raw matrix math with no ML framework doing the thinking for you.

### Part II 
Tokenization & Pretraining. Byte-Pair Encoding implemented from scratch, a real nanoGPT-style pretraining pipeline (warmup, cosine decay, gradient clipping, checkpointing), scaling laws you fit yourself, and the modern architecture upgrades (RoPE, RMSNorm, GQA, KV-cache) that separate a toy model from a real one.

### Part III
Applications & Agents. Prompt engineering and the LLM API layer, a tool-use agent loop built by hand, RAG implemented from first principles (not a framework's .query() call), and your first real production product.

### Part IV
Fine-tuning & Customization. The Hugging Face ecosystem, LoRA and QLoRA fine-tuning, alignment via RLHF and DPO, and quantization for local inference.

### Part V 
Capabilities. The Model Context Protocol (MCP), advanced multi-agent architectures, and memory systems — from basic context engineering to Letta-style persistent memory.

### Part VI 
Production Engineering. Model serving and inference optimization (vLLM), evaluation and observability, safety and security, and where to go next.

Plus a full glossary, a complete resource list, and an environment setup guide.
